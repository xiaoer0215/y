# Desktop Client v0.5.18

## 本次更新

- 重做客户端设置、账户、模型广场、使用日志与反馈页面布局。
- 反馈提交增加最小内容校验，并通过通知弹框反馈提交结果。
- 增加 Uocode、Nez Api、Yusr.ai 三个品牌构建配置。
- 修复 macOS 系统代理识别、登录状态锁和窗口标题显示问题。
- 同步 Windows 安装包、便携版与 macOS Apple Silicon / Intel 构建流程。

三个私有仓库分别发行对应站点客户端。Windows 提供 x64 安装版和便携版；Mac 的 aarch64 对应 Apple Silicon，x64 对应 Intel。

macOS 包尚未做 Apple Developer 公证。客户端已启用远程更新，更新清单需部署到对应品牌网站；私有仓库下载需要登录有权限的 GitHub 账号。
