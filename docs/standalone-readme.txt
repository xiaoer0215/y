Desktop Client - Windows x64 standalone edition

Extract all files to a folder and run the brand-named EXE in that folder.
Requires Windows 10/11 x64 and Microsoft Edge WebView2 Runtime.
WebView2 download: https://developer.microsoft.com/microsoft-edge/webview2/

This edition runs without an installer. Configuration is still
stored in the normal user profile, not beside the executable.

Use the Setup.exe edition to install shortcuts and handle missing WebView2.
This release is not code-signed and does not provide automatic updates.
